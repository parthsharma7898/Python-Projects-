# Personal Password Manager 🔐

A beginner-friendly Python CLI application for managing passwords
and generating random passwords.

## Features

- Save website passwords
- View saved passwords
- Generate random passwords
- Load previously saved passwords
- Simple command-line interface

## Technologies Used

- Python
- Random module
- String module
- File handling

## Concepts Practiced

- Dictionaries
- Functions
- Loops
- Conditional statements
- File handling
- Exception handling
- Random password generation

## How to Run

```bash
python password_manager.py

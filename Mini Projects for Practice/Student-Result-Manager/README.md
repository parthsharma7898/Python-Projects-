# Student Result Manager 📚

A beginner-friendly Python CLI application for managing student records and checking results.

## Features

- Add student records
- Store student marks
- View all students
- Check individual student results
- Display PASS / FAIL status
- Validate marks between 0 and 100
- Handle invalid input
- Exit option

## Technologies Used

- Python

## Concepts Practiced

- Dictionaries
- `while` loops
- `if-elif-else`
- User input
- Exception handling
- String methods
- Basic program logic

## How to Run

```bash
python student_result_manager.py
